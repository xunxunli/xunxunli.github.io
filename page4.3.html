UI Sprints


What's a UI Sprint?

A UI Sprint is a fast-paced project that is done to help develop design skills and allow for a designer to practice. It's an opportunity to try new things and receive constructive feedback to help designers improve.

In my course, UI Sprints are design challenges that are given every other week to think about and solve.


UI Sprint #1: Democrat and Chronicle Collection Mobile Redesign

In this UI sprint, students were shown the following webpage screenshot:

This page is an original design for a photography collection that was being released with Democrat and Chronicle. Our design challenge is to redesign this page for mobile to better cater to the users as well as better showcase Democrat and Chronicle's brand image.

A few problems that I see with this current design:

  • It's hard to read with so many harshly contrasting font sizes
  • The colored text is difficult to read
  • Not similar to existing Democrat and Chronicle brand styling
  • It's about a photography collection, yet there is no photos!

Democrat & Chronicle's current website for style reference:

  • Lots of blue accent colors
  • Usage of helvetica neue and PT serif fonts
  • Looks modern

My new take on the collection site (for mobile screens):

  • Utilizes both blues found on the shortened D&C logo
  • A clean, modern take that utilizes D&C's preferred helvetica neue, PT serif, and one accent font
  • Keeps emphasis on the photography
  • Provides a clear action button
